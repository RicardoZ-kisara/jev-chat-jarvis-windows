# Jev QQ Windows 0.1.0 Preview

QQ Windows 专用的首个可运行预览版。基于 jev-chat/jev-chat-jarvis，保留上游 Android 工程和 MIT 许可。

- QQ 窗口筛选、按窗口句柄截图、区域选择、离线中英文 OCR。
- Jev 七题判断、三条候选生成与排序、复制、受控填入；发送始终手动。
- 导入可读 QQ JSON / UTF-8 TXT，按联系人或群聊去重和存储。
- 分段生成关系观察、关键事件、待办档案，支持暂停续跑和原消息引用。
- 关联长期档案及相关历史片段，辅助当前回复。
- 模型地址、密钥与模型名称可配置；密钥由 Windows 加密。

下载 Setup 为安装版，Portable 为免安装版。两个包都含 OCR 模型，不需要 Node.js 或 Python。使用前请配置自己的模型 API，或使用本机兼容服务。长期档案可产生多次模型请求，界面先展示分析范围与最多请求数。

验证：17/17 逻辑测试通过；合成数据与本机 mock 接口的实际桌面流程通过；10,000 条合成历史导入和检索通过。生产模型接口、实际 QQ 各版本输入框兼容性未验证。直接填入不支持时使用复制。

当前不直接读取 QQ NT 原始数据库，按用户确定的入口使用可读导出文件。历史副本保存在应用用户目录的明文 SQLite；聊天数据不会随代码发布。首版未进行代码签名。

详情见 `windows/README.md`、`windows/QQ_HISTORY.md` 和 `windows/QA.md`。SHA256 校验及源码/包一致性清单随 Release 附带。
